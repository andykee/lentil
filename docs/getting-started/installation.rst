Installation
============

If you are new to Python and/or do not have familiarity with `Python virtual
environments <https://docs.python.org/3/tutorial/venv.html>`_, then we 
recommend starting by installing the `conda <https://docs.conda.io/en/latest/>`_
package manager distributed by `miniforge <https://github.com/conda-forge/miniforge>`_
This works on all platforms (Linux, MacOS, Windows) and installs a full-featured 
scientific Python in a user directory without requiring root permissions.


To install using **pip**:

.. code-block:: bash

    pip install lentil

Requirements
============
Lentil has the following package dependencies:

* `Python <https://www.python.org>`_ 3.8 or later
* `numpy <https://numpy.org>`_ 2.0 or later
* `scipy <https://scipy.org>`_
