Sampling#

The accuracy of a numerical diffraction simulation depends on adequately sampling the input and output planes. This section describes how to select appropriate sampling fand how to configure propagations to avoid introducing numerical artifacts.

Output sampling and aliasing#

The relationship between spatial sampling in the input plane and output plane is described by

\[Q = \frac{\lambda \ F/\#}{\Delta u}\]

where \(\lambda\) is wavelength, \(F/\#=f/D\) is focal length divided by the pupil diameter, and \(\Delta u\) is output pixelscale.

The intensity of a diffraction pattern contains no spatial frequencies above \(1/(\lambda F/\#)\), so the output is Nyquist sampled for intensity when \(Q \ge 2\). Aliasing is obvious below \(Q = 1.5\):

A helper function pixelscale_nyquist() returns pixelscale that gives \(Q = 2\).

Oversampling#

If detector pixel size, wavlength, and F/# are fixed and \(Q < 2\), the output can be computed on a finer grid by specifying oversample. The result has shape * oversample pixels sampled at pixelscale / oversample, and

\[Q_{\mathrm{os}} = Q \cdot \mathtt{oversample}\]

Choose oversample so that \(Q_{\mathrm{os}} \ge 2\), then rebin the intensity back to native sampling:

# f/10, 650 nm, 5 um pixels -> Q = 1.3
oversample = int(np.ceil(2 / 1.3))    # 2

w = lentil.propagate_dft(w, pixelscale=5e-6, shape=64,
                         oversample=oversample)
img = lentil.rebin(w.intensity, oversample)    # (64, 64)

Input sampling and periodic wraparound#

The Fourier transform of a sampled pupil is periodic. The output repeats with period

\[P = \frac{\lambda z}{\Delta x} = N \lambda F/\#\]

where \(\Delta x\) is the input pixelscale, \(z\) is the focal length, and \(N = D/\Delta x\) is the number of samples across the pupil. Light more than \(P/2\) from the optical axis wraps around to the other side of the output plane:

Be careful to limit the output field of view to fall within half a period so that neighboring copies don’t contaminate the output:

\[\mathtt{shape} \cdot \Delta u \le \frac{P}{2} \quad\Longleftrightarrow\quad \mathtt{shape} \le \frac{N \, Q}{2}\]

where shape is in native (not oversampled) pixels. For example, a pupil 240 pixels across imaged at \(Q = 1.3\) supports an output up to 156 pixels across. To go larger, sample the pupil more finely with rescale().

The same limit applies to tilt: a tilt that moves the PSF more than \(P/2\) aliases. Lentil avoids this limit with a separate path for tilt, described in Propagation with large tilts.

Image to pupil propagations#

The same relations hold for image to pupil propagation, although the effects are slightly different:

  • The re-imaged pupil must fit inside one period, \(\lambda z / \Delta x\), where \(\Delta x\) is now the image plane pixelscale.

  • The image plane field of view, shape * pixelscale, limits the finest detail in the re-imaged pupil to roughly \(\lambda z / (\mathtt{shape} \cdot \Delta x)\). A small image plane acts as a field stop. See Multi-plane propagation.

Choosing sampling parameters#

  1. Set pixelscale to the detector pixel size, or to pixelscale_nyquist() if no detector is modeled.

  2. Compute \(Q\) and set oversample to at least \(2/Q\).

  3. Set shape to cover the region of interest. Check that \(\mathtt{shape} \le N Q / 2\). If it isn’t, sample the pupil more finely or reduce shape.

  4. For broadband models, run these checks at the shortest wavelength, where both \(Q\) and \(P\) will be smallest.
