Plane basics#

Overview#

Lentil represents optical systems using one or more planes that have some influence on a propagating wavefront. All planes in Lentil are described by a common set of attributes. The most commonly used attributes are:

  • amplitude - defines the electric field amplitude transmission through the plane

  • opd - defines the optical path difference that a wavefront experiences when propagating through the plane

  • mask - defines the binary mask over which the plane data is valid. If mask is 2-dimensional, the plane is assumed to be monolithic. If mask is 3-dimensional, the plane is assumed to be segmented with the individual segment masks provided along the first dimension. If mask is not provided, it is automatically created from the nonzero values in amplitude.

  • pixelscale - defines the physical sampling of the above attributes. A simple example of how to calculate the pixelscale for a discretely sampled circular aperture is given below:

  • ptype - specifies the plane type. Additional details are available in the sections describing How a plane affects a wavefront and Plane-wavefront multiplication rules

Plane creation#

Create a new plane with

p = lentil.Plane(amplitude=lentil.circle((256,256), 120))

Once a plane is defined, its attributes can be modified at any time:

p = lentil.Plane(amplitude=lentil.circle((256,256), 120))
p.opd = 2e-6 * lentil.zernike(p.mask, index=7)

Resampling and rescaling#

Plane sampling can be modified using the resample() or rescale() methods:

  • resample() modifies plane sampling to the provided pixelscale

  • rescale() adjusts plane sampling by the given scale factor

Both methods use intrepolation to resample the amplitude, opd, and mask attributes and update the plane’s pixelscale accordingly.
